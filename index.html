CFRP Swingarm Optimisation for Moto2 Motorcycle

Objective

Convert an existing aluminium 7075-T6 double-sided Moto2 swingarm to a CFRP structure and apply three-stage composite optimisation to maximise stiffness-to-weight ratio under racing load cases, with Tsai failure index below 0.66.

Design and Modelling

Hybrid structure: solid aluminium for pivot, axle mounts, and shock linkage (~60% of total weight); shell CFRP for the main body (~40%). Baseline aluminium shell thickness of 2.5mm selected based on FOS analysis, giving a mass of 7.175 kg. Materials: T1100 UD (primary load direction) and T800 2x2 Twill prepreg (multi-directional load tolerance). FEA performed in Altair HyperMesh with OptiStruct solver using 2D shell elements (PCOMPP), with RBE3 connections at aluminium-CFRP interfaces.

Load Cases

Three static load cases: acceleration (8.42 m/s²), right cornering and left cornering (45° lean, 27.75 m/s, 40m radius). Constraints applied via SPC at swingarm pivot and shock linkage mount.

Mesh Convergence

Mixed quad/tria elements at 2.5mm selected. Moving from 2.5mm to 1mm increased stress and deformation by only 2.5% and 1.6% respectively, while computational time increased 250%.

Optimisation Stages

Free-size: 41.7% weight reduction but WCOMP increased 31.6% and failure index exceeded 0.66 — structurally unsafe.

Size (Tmax 8mm): Max failure index 0.12, WCOMP reduced 46.2% vs aluminium — overdesigned, 14.7% heavier.

Size (Tmax 5mm): Max failure index 0.267, WCOMP reduced 12.9%, laminate thickness 3.39mm, weight reduced 27.97%.

Shuffle optimisation: Stacking sequence optimised with manufacturing constraints (Twill outer plies, max 2 consecutive same-orientation, balanced ±45). Failure index in cornering reduced; WCOMP improved 1.85%.

Final Results

Total weight reduced from 7.175 kg to 5.168 kg (27.97% reduction). WCOMP reduced 14.55%. Tsai failure index below 0.3 for all load cases. Maximum laminate thickness 3.396mm, validated within 10% against Classical Laminate Theory (3.048mm).
